# Music Share 実装ロードマップ

## 1. 目標

家族と音楽や動画を共有できる、シンプルで安全なWebアプリを作る。

目的:
- Gmailログインで本人認証を行う
- 家族向けの限定プレイリストを作れる
- 投稿した動画や音楽をアップロードできる
- お気に入り管理ができる
- 共有リンクで家族と再生できる
- GitHub Pages で公開しつつ、Supabase + Cloudinary で本番運用レベルの機能を追加する

---

## 2. 最終構成案

### フロントエンド
- GitHub Pages
- 役割: UI、再生画面、一覧画面、ログイン画面

### 認証
- Supabase Auth
- 役割: Gmailログイン、セッション管理、ユーザー識別

### DB
- Supabase Database
- 役割: プレイリスト、いいね、お気に入り、動画メタ情報の保存

### 動画配信
- Cloudinary
- 役割: 動画アップロード、変換、配信、サムネイル生成

### 画像/サムネイル
- Cloudinary または Supabase Storage

## 8. 推奨開発方針

- まずは MVP を最短で作る
- Supabase と Cloudinary を本番前提で導入する
- GitHub Pages はフロント公開用として使う
- 重要な論点は「認証」「保存」「公開範囲」「アップロード」の4点を最初に固める

## 10. 結論

最初にやるべきなのは、単なる再生機能ではなく、
「認証 + プレイリスト保存 + 動画アップロード + お気に入り保存」
の4つを実装することです。

この4つが揃えば、家族向けのアプリとして十分に価値が出ます。
